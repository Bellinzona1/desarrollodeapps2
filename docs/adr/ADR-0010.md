# ADR-0010 — Docker Compose y CI con quality gates

**Estado:** Aceptada

## Contexto

El sistema debe levantarse con un comando y cada cambio debe verificarse solo.

## Decision

Dockerfile multi-etapa y `compose.yaml` (base, migraciones, app). GitHub Actions: Checkstyle, JUnit, JaCoCo (negocio ≥ 80/70), PIT ≥ 60 %, tests de integracion con Testcontainers, gitleaks, Trivy, migraciones sobre base vacia, humo de punta a punta, E2E con Playwright, k6 (50 usuarios × 5 min, p95 < 500 ms), ZAP baseline y ZAP activo autenticado.

## Consecuencias

El pipeline tarda varios minutos; los secretos de cada corrida se generan al azar.

**Referencias:** .github/workflows/ci.yml
