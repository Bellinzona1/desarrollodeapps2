# ADR-0009 — Frontend sin framework con CSP estricta

**Estado:** Aceptada

## Contexto

La materia evalua el backend; el frontend no debe sumar un paso de build ni superficie de ataque.

## Decision

HTML + CSS + modulos ES nativos, una pagina y un modulo por pantalla. Todo dato del servidor pasa por `esc()`. CSP sin scripts ni estilos en linea y sin origenes externos (fuente Inter alojada en el WAR).

## Consecuencias

Mas codigo manual de DOM. Ningun `npm build` para desplegar.
