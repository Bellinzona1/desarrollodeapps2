# ADR-0003 — Autenticacion con JWT y autorizacion en la capa de negocio

**Estado:** Aceptada

## Contexto

La API la consumen el frontend y otros clientes; los permisos deben valer para cualquier canal.

## Decision

JWT HS256 emitido por `POST /api/auth/login` y validado por un `HttpAuthenticationMechanism`. `@RolesAllowed` en los EJB y controles por dueno (BOLA) con `getCallerPrincipal()`. Secreto JWT solo por configuracion (aleatorio si falta).

## Consecuencias

Sin estado de sesion para autenticar; un token robado vale hasta que vence. Los permisos no dependen de la capa REST.
