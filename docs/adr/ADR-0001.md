# ADR-0001 — Jakarta EE 10 sobre WildFly con EJB para la logica de negocio

**Estado:** Aceptada

## Contexto

La catedra evalua Jakarta EE. La logica necesita transacciones, seguridad declarativa y concurrencia.

## Decision

La capa de negocio son EJB `@Stateless` (y un `@Stateful` para el asistente). Transacciones JTA y `@RolesAllowed` declarativos; WildFly 36 con el perfil `standalone-full` (trae JMS).

## Consecuencias

No se escribe codigo de transacciones ni de pool. Se depende de un servidor de aplicaciones completo. Descartado: beans CDI con `@Transactional` (sin seguridad declarativa por metodo).
